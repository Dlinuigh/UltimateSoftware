## 描述

教学向自研 SQL 数据库：固定页大小的文件存储、基础 SQL（SELECT/INSERT/UPDATE/DELETE、WHERE/ORDER BY/LIMIT、DDL、简单 JOIN）、单列/复合与 B+ 树索引，以及事务相关清单。

## 使用说明

```bash
git clone https://github.com/Dlinuigh/lionql
cd lionql
# 按仓库 CI / Makefile 或 README 中的构建步骤编译
```

克隆后查看仓库内构建与测试说明；CI 工作流见仓库 Actions。源码：<https://github.com/Dlinuigh/lionql>
